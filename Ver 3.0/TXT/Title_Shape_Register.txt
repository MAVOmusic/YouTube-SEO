# Created: 2026-11-02 (VER 4.29) - opened after MAVO's title correction.
#
# WHY THIS FILE EXISTS
#   MAVO (02-11-2026), verbatim:
#     "You started repeating again. Bandname's Song Title is .... Sabaton's
#      Dreadnought on bass, the ship that missed its own battle. 'Sabaton's'
#      appearing every time. Be more creative, Do not repeat. Title needs to be
#      unique. Redo the titles which have repetitive, robotic structure"
#
#   He was right and the drift was measurable. Ten of the twenty-eight titles
#   opened with a possessive band name - "Sabaton's Camouflage", "Green Day's
#   X-Kid", "Avril Lavigne's Together" - and the nine newest titles had collapsed
#   into two skeletons: "[Band]'s [Song] ..." and "[Song] is [Band] ...".
#
#   A title shape is not a template you can reuse. YouTube indexes the pattern as
#   well as the words, and a human reader sees the pattern long before they see
#   the words: the same file name with a different noun in it. Ver 3.5 banned
#   fixed shapes; this register enforces the ban with a written rule and a log.
#
# THE RULE
#   1. EVERY TITLE USES A DIFFERENT SYNTACTIC SKELETON. Not different words -
#      a different skeleton. If the previous title was a question, the next one
#      is not a question. If the last three opened with the band name, the next
#      one does not open with the band name.
#   2. THE POSSESSIVE OPENER IS BANNED. "[Band]'s [Song] ..." may not start a
#      title, at all, ever again. It is the single most repetitive thing the
#      channel did and it ran for ten straight videos.
#   3. "[SONG] IS [BAND] ..." IS BANNED as an opener for the same reason.
#   4. NO FIXED TURN OF PHRASE. "on bass", "at full sprint", "on one bassline"
#      and "and the bass carries it" are not allowed to become signatures either.
#      Three videos may not share the closing device.
#   5. EVERY TITLE CARRIES THE SEARCHABLE STRINGS - band name and song title -
#      but their POSITION moves: sometimes song first, sometimes band first,
#      sometimes both mid-sentence, sometimes a player's name carries the front
#      and the song lands at the back.
#   6. LENGTH: 48 to 69 characters as of Ver 4.29. Long enough for the search
#      terms, short enough that mobile does not cut the hook off.
#   7. BEFORE WRITING A NEW TITLE, READ THIS FILE. The new skeleton goes in the
#      log below at the same time the copy is written. No row, no title.
#

# HOW THIS FAILURE HAPPENED - recorded so it is not repeated
################################################################################
  Nothing about any single title was wrong. Every one of them was defensible in
  isolation. The failure was sequential: each new title was written against the
  song rather than against the twenty-seven titles already on the channel, so the
  most recent shape won by default. The n-gram guard could not catch it either,
  because "Sabaton's Dreadnought on bass" and "Sabaton's Camouflage is" share no
  six-word run. Shape repetition is invisible to string guards.

  The fix is procedural, not lexical: the skeleton is now a logged artefact, and
  step 7 above makes it a precondition.
