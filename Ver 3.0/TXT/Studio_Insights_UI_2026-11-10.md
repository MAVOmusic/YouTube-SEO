# YouTube Studio: Analytics became Insights

Recorded 2026-11-10 from the refreshed screenshots for .38 Special - If I'd Been The One, which are the first pair in this project captured after the change.

## What changed

The left sidebar item that used to read Analytics now reads **Insights**, and the video page it opens is headed **Video insights**. The four top cards are Reach, Engagement, Audience and Revenue, each with its own drill-down page, and every page carries an **Advanced mode** toggle in the top right.

The URL and the page names used in folder structures do not follow: the folders stay `_02 - Analytics`, because renaming them would break every existing path, the catalogue checker and the long-form gate.

## New cards worth knowing about

| Card | Where | Why it matters |
| --- | --- | --- |
| 48-hour views | Video insights, right column | Isolates the launch window from lifetime numbers, so a new upload can be judged on day two without waiting. |
| Insights from Ask Studio | Video insights, bottom | A generated summary of the video. It is AI written and labelled as such in the UI, so no figure is copied from it into copy or into a review without checking the card it came from. |
| How viewers found this video | Video insights, right column | Names the traffic type rather than the source list. |
| How viewers found this Short | Video insights | The Shorts equivalent. |
| Playlists featuring this video | Reach | Which playlists are actually driving views. This is new visibility into playlist performance. |
| Content suggesting this video | Reach | Which other videos put this one in front of viewers, with a share for each. |
| Subscriber notifications | Reach | Mobile push count, notification click-through and views from notifications. |
| Watch time from subscribers | Audience | Split between subscribers and non-subscribers. |
| Hype | Engagement | A first-seven-days card that reads Not enough data on older videos. |

## What this means for future reviews

- Screenshots should still come as one file per card group: Video insights, Reach, Engagement, Audience, Revenue. The existing folder names `_01 - Overview`, `_02 - Reach`, `_03 - Engagement`, `_04 - Audience` and `_05 - Revenue` still describe the new pages accurately.
- Reach is now paginated across two screens, and the second screen carries YouTube search terms, playlists featuring the video, content suggesting the video and subscriber notifications. Both pages are needed for a full read.
- Ask Studio summaries are useful as a cross-check on a reading, never as the source. The numbers come from the cards.
- The Advanced mode button hides nothing that the standard pages show in these captures, so no second pass is needed for it.
