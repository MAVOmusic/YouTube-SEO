# WHAT THE AUDIT FOUND (29 videos, before CO-0029)
#   DESCRIPTION OPENERS : 13 of 28 opened with a year or a release date.
#                         That is 46 percent of the catalogue using one
#                         device: "[Album] arrived in [year] and...". No string guard
#                         can see it, because the album names all differ.
#   PINNED COMMENTS     : 19 of 28 ended in a nomination question -
#                         "What is the best / most / favourite X you...". Every
#                         one of them asks the reader to supply a superlative.
#                         Twenty-eight videos, one conversational move.
#
# THE RULE
#   1. A description opens with a DEVICE, not with a fact. The device is chosen
#      from the pool below and logged here before the copy is written.
#   2. No device may be used twice within eight consecutive videos, and the
#      date-first opener may not exceed one in four across any window of twelve.
#   3. The pin must not repeat the device of the previous pin. A nomination
#      question is one device among many, not the default.
#   4. THE PIN MUST NOT MIRROR THE DESCRIPTION'S OPENING MOVE. If the
#      description opens with a question, the pin does not.
#   5. Prose is what gets read as spam. TAGS ARE KEYWORDS AND MAY REPEAT -
#      "bass cover", "rocksmith 2014" and "bass play along" are search
#      vocabulary and belong in every box. What must never repeat is a
#      sentence, a skeleton or a conversational move.
#   6. Scale note for 2500+ videos: this file holds one row per video and grows
#      by one row per audit. That is the point. The pool never runs dry because
#      each device has variants, and a device that has been away for eight
#      videos is fresh again.
#
