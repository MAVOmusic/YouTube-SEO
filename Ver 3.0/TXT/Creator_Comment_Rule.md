# Creator comment rule: every video gets a fact, quiz or trivia

Standing rule from the user, 2026-11-10:

> Every video gets a fact, quiz or trivia comment. No matter if anything pinned from someone else.

## What this means

Every video that gets a copy package also gets a creator comment, written as paste-ready text. That comment carries a fact, a quiz, a piece of trivia or a sourced question. It is a delivery requirement, not an optional extra, and it does not depend on what is already pinned.

## Two different surfaces

These are separate and must not be confused:

| Surface | Who owns it | What happens to it |
| --- | --- | --- |
| Pinned viewer or artist comment | A viewer, or the artist | Preserved exactly as it is. Never edited, never unpinned to make room, never replaced. |
| Creator fact, quiz or trivia comment | The channel | Always supplied. Posted as its own new comment. Pinned only if nothing genuine is already pinned there. |

A pinned viewer comment does not satisfy the rule and it does not excuse the creator comment. A video with somebody else's comment pinned still gets the creator comment, posted underneath it.

## On Shorts, the pointer comes first

A Short's comment opens with one line pointing at the attached full recording, then the quiz, fact or trivia. That ordering is fixed, and the description must carry the same pointer as its own block. Full detail in `Short_Full_Recording_Rule.md`, which also records why describing a Short as a cut, a trim or a separate recording is wrong on this channel.

## What counts

- A sourced fact with a question attached.
- A multiple-choice quiz with the answer kept out of the description, unless the description deliberately gives it away.
- A piece of trivia from the song, album, video or recording session.
- An opinion question anchored to a real fact.

What does not count: a bare greeting, a request to subscribe, a link drop, or a comment that only repeats the description.

## Variety across a batch

Do not make every comment in a batch the same shape. The X-Kid set of five mixes four quizzes with one fact-and-question so the format does not become a template. Answer options should be real near misses where the source supports them, not invented names.

## Where it is enforced

- Every `_03 - Copy.md` must carry a paste-ready creator comment block.
- Where a viewer or artist comment is preserved, the file carries both: the preserved pin record and the separate creator comment block.
- `Ver 3.0/TXT/Copy_Shape_Register.txt` records the pin device per video.
- `Ver 3.0/TXT/Historical_Quiz_Questions_And_Answers.md` records every quiz question, its options, its answer, the source and its status.
- `Ver 3.0/TXT/Long_Form_Release_Gate.txt` requires a review of the comment surface for long forms.

## Standing title and comment rules, registered 2026-11-11

Full consolidated list: Ver 3.0/TXT/Copy_Rules_Standing.md.
