# WHY THIS FILE EXISTS
#   MAVO (01-11-2026): "None of my long form videos are earning unless Revenue
#   Share or no Copyright on it. There are a few, we need to note them out then
#   recreate videos later so we can have some benefit of them."
#   Every LF audit capture prints the Studio "Notices" badge on the Details page.
#   That badge is the earning status. This register records it per video, per
#   claimant, so the re-record programme can be aimed at material that can
#   actually pay - instead of re-recording straight into another block.
#
# THE STATUS TAXONOMY (from the Details page Notices badge)
#   E1  EARNING-NO-CLAIM      green/amber, monetisation active, no Content ID
#                             claim. BEST. Recreate freely, same rights profile.
#   E2  EARNING-REV-SHARE     claimed, but the owner allows shared revenue.
#                             Revenue prints in Studio. GOOD. Recreate freely;
#                             expect the same claimant and a 50/50-ish split.
#   E3  CLAIMED-NOT-EARNING   claimed, owner keeps 100% (or ad revenue routed to
#                             owner). Video is live but pays us nothing.
#   E4  INELIGIBLE            red "Ineligible to earn". No ads of ours at all -
#                             copyright block, policy issue, or CDLC/download
#                             link. THIS IS THE CURRENT MAJORITY.
#   E5  BLOCKED               globally blocked / not viewable.
#   E6  UNKNOWN               no Notices badge visible in the capture.
#
# RECREATION RULES (what "recreate later so we can have some benefit" means)
#   1. Recreate E1 + E2 first - they are the only proven-earning rights profiles.
#   2. E3: recreate ONLY if the claimant is likely to differ on a different
#      arrangement/audio source (e.g. different mix, live version, isolated stem).
#      If the claimant matches the studio master 1:1, a remake pays the same and
#      is pointless - park it.
#   3. E4: diagnose the CAUSE before recreating. Two different animals:
#        E4-a  CLAIM-DRIVEN (audio Content ID block) -> a remake with a different
#              audio bed can escape it. Candidate.
#        E4-b  POLICY-DRIVEN (link / reused-content / CDLC download) -> a remake
#              is unnecessary; FIXING the metadata can restore eligibility.
#              Always test the cheap fix first.
#   4. E5: never recreate the same audio; the block follows the composition.
#   5. Remakes are NEW uploads (create/edit > "reuse details" is NOT the route).
#      Legacy video stays live unless the 0005-class exception applies.
#   6. Every remake gets a fresh package (LF+SF) and must clear the §29 gate.
#
# ⚠️ CDLC DOWNLOAD LINKS - THE SUSPECTED SYSTEMIC BLOCKER (see CO-0002)
#   The 2022 "100% CDLC" long-form series put a shortened download link to
#   custom Rocksmith DLC in every description ([CDLC DOWNLOAD LINK]
#   gestyy.com/...). Custom DLC distributes copyrighted songs outside the rights
#   holders' control. A description link to it is a monetisation/policy problem
#   independent of Content ID, and it is consistent with the whole 2022 LF
#   catalogue reading "Ineligible to earn". RULE (VER 3.3): no download links of
#   any kind in any description - no CDLC, no file hosts, no shorteners. If a
#   video is E4 and carries a CDLC link, remove the link first and re-check the
#   Notices badge before assuming a remake is needed.
